# Computer Control 개발 미리보기

<Callout type="warning">
**v0.7.1에는 포함되지 않았습니다.** 아래는 개발 브랜치의 기능 안내입니다. 정식 다운로드에서 이 메뉴나 CLI가 보이지 않는 것은 정상입니다. 전체 데스크톱 동작 검증은 진행 중이며 스크롤 등 일부 동작은 추가 확인이 필요합니다.
</Callout>

## 무엇을 하는 기능인가요?

Damson Computer는 선택한 macOS 앱의 창을 살펴보고 클릭·키 입력·텍스트 입력·화면 캡처를 수행하는 helper입니다. 터미널 pane은 `damson-cli`, 작업 순서는 `damson-crew`, 다른 앱의 화면 조작은 `damson-computer`가 담당하는 구조입니다.

별도 helper 앱인 **Damson Computer.app**을 Damson 앱 내부에 함께 넣는 방식으로 개발하고 있습니다. macOS 권한은 이 helper에 부여합니다. 일반 터미널 사용이나 v0.7.1의 crew 워크플로를 위해 설치할 필요는 없습니다.

## 개발 빌드에서 제어판 열기

1. Damson의 **Tools → Computer Control…**을 엽니다.
2. 제어판에서 helper 실행 상태와 권한 상태를 확인합니다.
3. **Accessibility Settings…**로 macOS 접근성 설정을 열고 **Damson Computer**를 활성화합니다.
4. **Screen Recording Settings…**에서 화면 기록 권한을 설정합니다. macOS 버전에 따라 항목 이름이 다를 수 있습니다.
5. 목록에 앱이 없다면 **Show Helper in Finder**로 정확한 helper 위치를 확인해 추가합니다. macOS가 재시작을 요청하면 helper를 다시 시작합니다.

이 메뉴는 시스템 설정을 여는 기능입니다. 권한을 자동으로 허용하지 않습니다. helper의 **DC** 메뉴에서도 설정 바로가기와 Stop을 사용할 수 있습니다.

## 제어 세션과 중단

제어는 선택한 앱의 PID와 실행 식별자에 묶인 세션으로 수행합니다. 한 번에 하나의 세션만 데스크톱을 소유하며, 세션은 제한 시간이 지나면 만료됩니다. 앱이 재시작되면 대상을 다시 확인해야 합니다.

사용자가 마우스나 키보드를 사용하거나 **Stop**을 누르면 제어가 중단됩니다. 다시 진행할 준비가 되었을 때 **Resume**하고 새 세션을 시작하는 흐름입니다. 에이전트가 사용자 중단을 임의로 해제해서는 안 됩니다.

클릭 요청을 보냈다는 응답만으로 버튼의 실제 동작 성공을 단정하지 않습니다. 접근성 상태나 캡처로 결과를 확인해야 합니다. 게임 제작 뒤 실제 플레이 테스트를 연결하는 것도 이 검증이 완료되어야 신뢰할 수 있습니다.
