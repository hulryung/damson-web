# 설치와 첫 실행

## 앱 설치

1. macOS 13 Ventura 이상에서 [Damson.dmg 다운로드](https://github.com/hulryung/damson/releases/latest/download/Damson.dmg)를 엽니다. 배포 파일의 지원 아키텍처는 [릴리즈 페이지](https://github.com/hulryung/damson/releases/latest)에서 확인하세요.
2. DMG 안의 **Damson.app**을 **Applications** 폴더로 옮깁니다.
3. Applications 또는 Spotlight에서 Damson을 실행합니다.
4. 열린 터미널에 `pwd`를 입력하고 Return을 눌러 셸이 동작하는지 확인합니다.

## 업데이트

**Settings → Advanced → Check for Updates…**에서 수동으로 확인할 수 있습니다. **Automatic Updates**를 켜면 백그라운드에서 업데이트를 확인합니다. 자동 업데이트는 기본적으로 꺼져 있습니다.

앱과 번들 CLI는 함께 업데이트하세요. 별도로 복사해 둔 오래된 CLI는 새 앱과 기능이 다를 수 있습니다. Claude 플러그인은 앱 업데이트와 별도로 관리합니다.

## CLI 준비

별도 CLI 패키지를 설치할 필요는 없습니다. 다음 명령은 앱 안에 포함된 도구의 도움말을 표시합니다.

```sh
/Applications/Damson.app/Contents/Resources/damson-cli --help
/Applications/Damson.app/Contents/Resources/damson-crew --help
```

짧은 명령으로 쓰려면 현재 셸의 PATH에 앱의 Resources 폴더를 추가합니다.

```sh
export PATH="/Applications/Damson.app/Contents/Resources:$PATH"
damson-cli --list-instances
```

계속 사용하려면 위 `export` 한 줄을 zsh의 `~/.zshrc`에 추가하고 새 터미널을 여세요. 앱을 다른 위치에 설치했다면 경로도 변경합니다.

## 코딩 에이전트 준비

Damson은 에이전트 실행을 관리합니다. Claude Code나 Codex 같은 에이전트 자체의 설치·로그인까지 대신하지는 않습니다. 사용하려는 에이전트를 터미널에서 먼저 실행해 로그인과 기본 작업이 되는지 확인하세요.

**Settings → Agents → Command**에서 기본 에이전트를 지정합니다. Claude의 **Skip permission prompts**는 기본적으로 켜져 있으며 파일 수정과 명령 실행을 매번 묻지 않게 합니다. 승인 요청을 직접 확인하려면 이 설정을 끄세요.
