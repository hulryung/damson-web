# 화면 구성 프리셋

매번 분할 경계를 끌어 조절하는 대신, 단축키 하나로 작업 공간을 구성하세요.

## 일곱 가지 기본 구성

| 단축키 | 구성 | 배치 |
| --- | --- | --- |
| `⌘⌃1` | 20 / 60 / 20 열 | 가운데가 넓은 세 열 |
| `⌘⌃2` | 두 열 | 좌우 50 / 50 |
| `⌘⌃3` | 세 열 | 33 / 33 / 33 |
| `⌘⌃4` | 두 행 | 위아래 분할 |
| `⌘⌃5` | 2 × 2 격자 | 같은 크기의 네 창 |
| `⌘⌃6` | 주 작업 + 오른쪽 | 70 / 30 |
| `⌘⌃7` | 주 작업 + 오른쪽 상하 | 넓은 왼쪽과 오른쪽 두 창 |

## 가운데에 집중하기

20 / 60 / 20 구성은 가운데 60%를 주 작업에 쓰고, 양쪽 20%에는 로그·파일 감시·코딩 에이전트를 배치하기 좋습니다. `⌘⌃1`을 누르면 바로 적용됩니다.

[작업 공간 복원](/ko/tabs-and-panes)과 함께 사용하면 익숙한 배치를 유지할 수 있습니다. 새로운 작업을 시작할 때는 다른 프리셋으로 전환하세요.

## 에이전트 작업 공간

`⌘⌃7`은 주 작업 옆에 에이전트나 테스트 창 두 개를 두기 좋습니다. [GPU 렌더링](/ko/features/gpu-rendering)과 함께 여러 출력 흐름을 한 화면에서 확인할 수 있습니다. 실행 관리 방법은 [여러 에이전트 실행](/ko/manual/agents)을 참고하세요.
