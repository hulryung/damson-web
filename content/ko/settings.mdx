# 설정

`⌘,`로 설정을 엽니다. 대부분의 변경은 즉시 적용되며 밝은·어두운 테마 전환도 바로 확인할 수 있습니다. 앱의 메뉴 이름은 영문으로 표시될 수 있습니다.

## 글꼴과 텍스트

- 글꼴 종류와 크기
- 프로그래밍 합자 사용 여부
- 두 칸 크기 아이콘 표시
- 폭이 모호한 기호를 두 칸으로 처리
- 더블클릭 선택 범위를 결정하는 단어 구분자

아이콘과 기호 폭의 차이는 [기호와 한글 폭](/ko/glyph-width)에 설명했습니다.

## 테마와 화면

- 밝은·어두운 테마
- 배경 투명도와 흐림
- 격자 주변의 가로·세로 여백
- 투명한 탭 표시줄과 스크롤바 표시
- 강도를 조정할 수 있는 CRT 화면 효과
- 글자 등장·사라짐 애니메이션

## 커서·탭·분할 창

커서 모양과 깜빡임, 탭 스타일, 탭 전환 방식, 선택한 창 표시, 마우스를 따라 입력 대상 이동, 전체 애니메이션과 새 탭의 시작 폴더를 설정합니다.

## 출력 기록과 입력

저장할 이전 출력 줄 수는 기본 10,000줄입니다. 출력 기록 복원, 스크롤 속도, 선택 시 복사와 키 길게 누르기 동작을 조정할 수 있습니다.

## 에이전트

**에이전트(Agents)**에서 기본 실행 명령, 승인 생략, 상태 알림과 작업 트리 경로를 설정합니다. **설치(Setup)**에서는 번들 CLI와 에이전트 스킬을 설치하거나 갱신합니다.

## 업데이트

**고급(Advanced)**에서 자동 업데이트 확인을 켜거나 **Check for Updates…**로 직접 확인합니다. 단축키 안내는 [빠른 시작](/ko/getting-started)을 참고하세요.
