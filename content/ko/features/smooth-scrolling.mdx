# 부드러운 스크롤

웹 페이지를 읽듯 이전 터미널 출력을 살펴볼 수 있도록 설계했습니다.

## 손끝에서 느껴지는 차이

- **최대 120Hz:** 지원하는 ProMotion 화면의 주사율과 동기화합니다.
- **픽셀 단위 이동:** 줄 전체가 한 번에 바뀌는 대신 작은 움직임도 반영합니다.
- **관성과 탄성:** 손을 떼면 점차 멈추고, 출력의 위아래 끝에서는 탄성 효과를 제공합니다.

목표는 Safari에서 페이지를 스크롤할 때처럼 자연스러운 움직임입니다.

## macOS에 맞춘 구현

AppKit, QuartzCore, CoreVideo를 직접 사용하여 Mac의 스크롤과 화면 동작을 반영합니다. Metal 렌더러는 `CAMetalLayer`에 그리고 `CVDisplayLink`로 화면 주사율에 맞춥니다.

터미널 입출력은 주 스레드 밖에서 처리하고 링 버퍼로 전달합니다. 자세한 렌더링은 [GPU 렌더링](/ko/features/gpu-rendering), 설계 기록은 저장소의 `docs/SMOOTH-SCROLL.md`를 참고하세요.
