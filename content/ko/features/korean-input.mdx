# 한글 입력

빠르게 입력할 때 첫 자모가 빠지거나 글자 조합이 뒤섞이는 문제를 줄이기 위해 macOS 한글 입력기 처리에 집중했습니다.

## 입력과 표시

- 첫 자모가 입력 이벤트 처리 과정에서 유실되지 않도록 처리합니다.
- 빠른 입력의 조합·확정 순서를 관리합니다.
- 조합 중인 글자는 별도 창이 아니라 터미널의 현재 입력 위치에 밑줄과 함께 표시합니다.

## 첫 글자가 사라지는 원인

키 이벤트 도착과 입력기의 조합·확정 요청 사이에는 미묘한 타이밍 차이가 있습니다. Damson은 `NSTextInputClient`를 구현하고 이 요청들의 순서를 처리합니다.

## 한글 대체 글꼴

주 글꼴에 없는 한글은 대체 글꼴로 표시합니다. 동아시아 전각 문자를 두 칸으로 계산하여 열을 맞춥니다. 기호의 폭은 [기호와 한글 폭](/ko/glyph-width)에서 별도로 설명합니다.

설계 기록: 저장소의 `docs/KOREAN-IME.md`, `docs/KOREAN-FONT-CASCADE.md`.
