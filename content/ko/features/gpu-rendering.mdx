# GPU 렌더링

CoreText가 글자 모양을 구성하고 Metal이 화면을 합성합니다. 출력이 계속되는 동안에도 글자와 스크롤을 효율적으로 갱신하도록 설계했습니다.

## 표시할 수 있는 내용

- 24비트 RGB 색상
- 굵게·기울임·밑줄·취소선과 OSC 8 하이퍼링크
- 두 칸을 사용하는 한글·CJK 문자
- ZWJ 조합과 국기를 포함한 컬러 이모지
- CoreText를 이용한 프로그래밍 합자
- 기본 글꼴에 없는 원문자 같은 기호의 대체 글꼴 표시

## 렌더링 흐름

텍스트를 NFC로 정규화하고 동아시아 문자 폭을 계산합니다. CoreText로 구성한 글자 이미지는 GPU 캐시에 보관하고 Metal 셰이더가 `CAMetalLayer`에 합성합니다. 이미 만든 글자를 재사용하여 다시 그리는 비용을 줄입니다.

[부드러운 스크롤](/ko/features/smooth-scrolling)과 [분할 화면](/ko/tabs-and-panes)을 함께 사용하면 여러 코딩 에이전트의 출력을 한 화면에서 볼 수 있습니다.

설계 기록은 저장소의 `docs/METAL-RENDERER-PLAN.md`에 있습니다.
