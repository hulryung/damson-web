# 주요 기능

Damson은 Swift, Metal, CoreText로 만든 macOS 전용 터미널입니다. 여러 플랫폼에 맞추는 대신 Mac의 입력·화면·창 시스템에 집중합니다.

- **부드러운 스크롤:** 지원 화면에서 최대 120Hz, 픽셀 단위 이동, 관성과 끝부분의 탄성 효과를 제공합니다.
- **한글 입력:** macOS 입력기의 첫 자모 처리와 조합 중인 텍스트를 터미널 안에서 다룹니다.
- **GPU 렌더링:** 24비트 색상, 텍스트 스타일, 두 칸 CJK 문자, 컬러 이모지와 대체 글꼴을 지원합니다.
- **매일 쓰는 작업 공간:** 탭·분할 화면, 설정, 배치 복원, 업데이트와 CLI 제어를 제공합니다.
