# 탭과 분할 화면

탭으로 작업을 구분하고 하나의 탭 안에서 화면을 여러 개로 나눕니다. 키보드로 이동과 배치를 제어할 수 있습니다.

## 탭

| 작업 | 단축키 |
| --- | --- |
| 새 탭 | `⌘T` |
| 탭 닫기 | `⌘W` |
| 다음 / 이전 탭 | `⌘⇧]` / `⌘⇧[` |

탭 전환 애니메이션과 탭 표시 방식은 [설정](/ko/settings)에서 고릅니다. 투명한 탭 표시줄도 사용할 수 있습니다.

## 분할 창

한 창을 두 개로 나누고 그 안에서 다시 분할하는 트리 구조입니다.

| 작업 | 단축키 |
| --- | --- |
| 좌우 분할 | `⌘D` |
| 상하 분할 | `⌘⇧D` |
| 왼쪽·오른쪽·위·아래 창 선택 | `⌘⌥` + 방향키 |
| 인접 창과 위치 교환 | `⌘⇧` + 방향키 |

선택 이동은 배치를 바꾸지 않고 입력 대상을 바꿉니다. 위치 교환은 작업을 종료하지 않고 두 창의 자리를 바꿉니다. [화면 구성 프리셋](/ko/preset-layouts)을 쓰면 한 번에 전체 배치를 적용할 수 있습니다.

## 입력 대상 표시

선택되지 않은 분할 창을 어둡게 하여 현재 입력 대상을 구분할 수 있습니다. 마우스를 따라 입력 대상을 바꾸는 옵션도 설정에서 켜거나 끕니다.

## 작업 공간 복원

다시 실행할 때 탭과 배치를 복원하고, 옵션에 따라 이전 출력도 복원할 수 있습니다. **배치 복원과 실행 중인 프로세스 유지는 서로 다른 기능**입니다. 지원되는 재시작에서 프로세스까지 유지하려면 [세션 유지](/ko/manual/terminal#재시작해도-작업을-유지하려면)의 설정과 제한을 확인하세요.
