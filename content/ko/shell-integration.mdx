# 셸 통합

OSC 133 프롬프트 표시를 통해 각 명령의 시작과 끝을 구분합니다. 명령 단위로 이동하고 결과를 복사할 수 있습니다.

## 프롬프트 탐색

| 작업 | 단축키 |
| --- | --- |
| 이전 프롬프트 | `⌘↑` |
| 다음 프롬프트 | `⌘↓` |
| 마지막 명령 출력 복사 | `⌘⇧C` |

빌드를 시작한 위치로 바로 돌아가거나, 직접 드래그하지 않고 직전 출력을 복사하세요.

## 이전 출력 검색

`⌘F`를 누르면 검색 표시가 열립니다. 다음·이전 결과로 이동하며 이전 출력을 찾을 수 있습니다.

## 주소와 파일 경로 열기

여러 줄에 걸친 URL을 인식하며 다음 줄의 관계없는 내용을 주소에 붙이지 않습니다. 파일 경로는 `⌘`를 누른 채 클릭합니다.

- 상대 경로: `Sources/App.swift`
- 절대 경로: `/usr/local/bin/tool`
- 줄 번호 포함: `file.swift:42`
- 도구 출력: `⏺ Update(docs/DESIGN.md)`

경로는 해당 세션의 작업 폴더를 기준으로 해석하며 실제 존재하는 파일만 연결합니다.

프롬프트 이동과 마지막 출력 복사에는 셸의 OSC 133 지원이 필요합니다. zsh·bash·fish에서 사용하는 셸 통합 설정을 확인하세요.

## tmux 제어 모드

tmux 제어 모드를 통해 tmux 세션을 Damson의 탭과 분할 창에 연결할 수 있습니다. 세부 동작은 저장소의 `docs/TMUX-INTEGRATION.md`를 참고하세요.
