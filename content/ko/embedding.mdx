# 엔진 임베딩

**DamsonTerminal**은 앱과 같은 VT 파서, 터미널 격자와 Metal 렌더러를 제공하는 Swift 패키지입니다. 자체 macOS 앱에 터미널 화면을 넣을 수 있습니다.

## 제공하는 구성 요소

- Metal, MetalKit, CoreText, AppKit, QuartzCore, CoreVideo를 사용하는 외부 의존성 없는 엔진
- GPU 렌더링, 부드러운 스크롤과 한글 입력 처리
- Swift에서 사용하는 설정·세션·콜백·화면 API

## API 구조

`DamsonConfig`는 글꼴·테마·출력 기록 등 시작 설정을 담습니다. `DamsonSession`은 입력 쓰기, 크기 조절, 이전 출력과 검색을 제공합니다. `onURLClick`, `onBell`, `onExit` 같은 콜백으로 호스트 앱과 연결합니다. 터미널 화면은 SwiftUI·AppKit 계층에 배치합니다.

```swift
import DamsonTerminal

// 실제 생성자와 옵션은 사용 중인 패키지의 API를 확인하세요.
let config = DamsonConfig(/* 글꼴, 테마, 출력 기록 등 */)
let session = DamsonSession(config: config)
session.onURLClick = { url in NSWorkspace.shared.open(url) }
```

위 코드는 구조를 보여주는 예시입니다. 정확한 시그니처는 사용 중인 소스와 저장소의 `docs/ARCHITECTURE.md`를 확인하세요.

## 프로젝트에 추가

[Damson 저장소](https://github.com/hulryung/damson)를 SwiftPM 의존성으로 추가하고 `DamsonTerminal`을 가져옵니다. 앱과 같이 macOS 13 이상을 대상으로 합니다.

IDE, 장치 콘솔, 교육 도구처럼 내장 터미널이 필요한 앱에서 VT 엔진을 새로 구현하지 않고 사용할 수 있습니다.
