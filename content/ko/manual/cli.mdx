# CLI로 터미널 제어

`damson-cli`는 실행 중인 Damson에 명령을 보냅니다. 먼저 앱을 열고 [CLI PATH 설정](/ko/manual/installation#cli-준비)을 적용하세요.

## 현재 상태 보기

```sh
damson-cli --list-instances
damson-cli list-tabs
damson-cli list-panes
damson-cli agents
```

여러 Damson 인스턴스가 있으면 `--pid`로 대상 앱을 고릅니다. `agents`나 `spawn` 응답의 안정적인 분할 창 ID를 저장하면 사용자가 다른 탭으로 이동해도 정확한 작업 대상으로 명령을 보낼 수 있습니다.

## 탭과 분할 만들기

```sh
damson-cli new-tab
damson-cli split horizontal
damson-cli list-panes
```

실행 명령과 작업 폴더를 지정해 새 pane을 열 수도 있습니다. 아래 경로는 실제 프로젝트 폴더로 바꾸세요.

```sh
damson-cli spawn --cwd "$HOME/dev/my-project" --key project-shell --title Project --group demo -- /bin/zsh -l
```

같은 `--key`로 재요청하면 기존 pane을 돌려주므로 중복 생성을 피할 수 있습니다.

## 특정 pane에 입력하기

아래 `12345`와 `PANE_ID`는 조회 결과로 바꿉니다. 텍스트 전송과 Return 입력은 별도 명령입니다.

```sh
damson-cli --pid 12345 --pane PANE_ID reveal-pane
damson-cli --pid 12345 --pane PANE_ID send-text 'pwd'
damson-cli --pid 12345 --pane PANE_ID send-key enter
damson-cli --pid 12345 --pane PANE_ID dump-grid
```

`dump-grid`는 현재 보이는 화면을 읽습니다. 명령의 종료나 테스트 성공 여부를 판정하는 전체 로그 대신 사용할 수는 없습니다. 지정한 pane이 사라지면 오류가 나며 활성 pane으로 대체해서 입력하지 않습니다.

## 자주 쓰는 명령

| 명령 | 용도 |
| --- | --- |
| `switch-tab 0` | 첫 번째 탭 선택, 인덱스는 0부터 |
| `focus-pane left` | 왼쪽 분할 창 선택 |
| `resize-pane right 3` | 분할 경계 조절 |
| `set-title 'Tests'` | 대상 탭 이름 지정 |
| `pane-info` | 대상 분할 창 정보 |
| `watch-agents` | 에이전트 상태 변경을 NDJSON으로 구독 |
| `group list` | 그룹 조회 |
| `group collapse demo` | 그룹 접기 |
| `group close demo` | 그룹의 탭과 실행 중인 프로그램 종료 |

설치한 버전의 전체 옵션은 `damson-cli --help`에서 확인하세요. 종료 코드 0은 요청 성공, 1은 앱이 반환한 명령 실패, 2는 연결·대상 탐색·인자 오류입니다.
