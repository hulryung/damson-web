# 터미널과 설정

## 탭과 분할 화면

탭은 작업 단위를 나누고, pane은 같은 탭 안에서 화면을 분할합니다. 예를 들어 편집기·개발 서버·테스트 명령을 각각 다른 pane에 둘 수 있습니다.

| 작업 | 기본 단축키 |
| --- | --- |
| 새 탭 | ⌘T |
| 좌우 분할 | ⌘D |
| 상하 분할 | ⌘⇧D |
| 다음 / 이전 탭 | ⌘⇧] / ⌘⇧[ |
| 인접 pane으로 이동 | ⌘⌥방향키 |
| 검색 | ⌘F |
| 설정 | ⌘, |

단축키를 변경했다면 **Settings → Keys**와 현재 메뉴의 표시가 우선합니다. 자주 쓰는 화면 구성은 [화면 구성 프리셋](/ko/preset-layouts), 탭과 분할 창 이동은 [탭과 분할 화면](/ko/tabs-and-panes)를 참고하세요.

## 출력 확인과 입력

트랙패드로 이전 출력을 스크롤하고 ⌘F로 텍스트를 찾습니다. 한글은 macOS 입력기를 그대로 사용합니다. 폰트에 따라 기호·한글 폭이 어긋난다면 [기호와 한글 폭](/ko/glyph-width)의 설정을 확인하세요.

셸 통합이 활성화된 셸에서는 프롬프트 사이 이동과 마지막 명령 출력 복사를 사용할 수 있습니다. 설정 방법과 지원 범위는 [셸 통합](/ko/shell-integration)에 설명되어 있습니다.

## 설정 찾기

| Settings 탭 | 주로 조정하는 항목 |
| --- | --- |
| Appearance | 폰트, 테마와 텍스트 표시 |
| Window | 창과 탭 표시, 분할 창 동작 |
| Effects | 화면 효과 |
| Terminal | 스크롤백, 커서, 입력 동작, 세션 유지 |
| Keys | 키보드 단축키 |
| Agents | 기본 에이전트, 승인 생략, 알림, worktree 경로 |
| Advanced | 자동 업데이트, 수동 업데이트 확인 |

## 재시작해도 작업을 유지하려면

**Settings → Terminal → Sessions**에서 세션 유지 옵션을 켭니다. 기본값은 꺼짐입니다. 지원되는 **Restart Damson**, 업데이트 설치, 종료 대화상자의 **Keep Sessions & Quit**에서는 `damson-keeper`가 실행 중인 터미널 세션을 맡았다가 다음 실행에 연결합니다.

일반 **Quit**은 실행 중인 프로그램도 종료합니다. 화면·스크롤백 복원만으로 이전 프로세스가 살아 있다는 뜻은 아닙니다.

현재 세션 유지는 compact 탭 모드가 대상이며, tmux pane과 `tmux -CC` 클라이언트는 이 인계 대상에서 제외됩니다. 앱 충돌이나 macOS 재부팅까지 작업을 보존하는 기능은 아닙니다. 인계 후 15분 안에 앱이 세션을 회수하지 않으면 keeper가 세션을 닫습니다.
