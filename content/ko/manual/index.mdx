# Damson 사용 설명서

Damson은 macOS 전용 터미널입니다. 탭과 분할 화면에서 작업하고, 함께 제공되는 CLI로 터미널을 제어하거나 여러 코딩 에이전트의 작업을 실행할 수 있습니다.

**문서 기준: v0.8.2 · 2026년 9월 14일.** 메뉴 이름은 앱에 표시되는 영어 이름을 사용합니다. 이후 버전의 변경 내용은 [릴리즈 노트](https://github.com/hulryung/damson/releases)에서 확인하세요.

## 어떤 도구를 사용하나요?

| 하고 싶은 일 | 도구 | 제공 여부 |
| --- | --- | --- |
| 셸 명령 실행, 탭·분할 화면 사용 | Damson.app | 제공 |
| 탭 생성, 특정 분할 창에 입력, 출력 읽기 | damson-cli | 앱에 포함 |
| 여러 에이전트 실행, 의존성에 따른 작업 진행 | damson-crew | 앱에 포함 |
| 지원되는 재시작에서 실행 중인 세션 유지 | damson-keeper | 앱이 내부적으로 사용 |
| 다른 macOS 앱의 화면 확인·클릭·입력 | Damson Computer / damson-computer | v0.8.0부터 포함 |

## 목적에 맞게 시작하기

일반 터미널로 사용하려면 **설치 → 터미널과 설정** 순서로 읽으세요. 에이전트 여러 개를 직접 지켜보며 작업하려면 **여러 에이전트 실행**, 선행 작업과 검증을 자동으로 연결하려면 **워크플로와 게임 제작**을 따라가세요.

<Callout type="info">
“게임을 만들어줘”라는 문장만 터미널에 입력하면 자동으로 작업이 분해되지는 않습니다. 코딩 에이전트와 오케스트레이션 스킬이 계획을 만들고, damson-crew가 그 계획을 실행합니다. 최종 결과물은 테스트와 실제 실행으로 확인해야 합니다.
</Callout>
