# 빠른 시작

[설치](/ko/installation)를 마쳤다면 다음 기능부터 사용해 보세요.

## 자주 쓰는 단축키

| 작업 | 단축키 |
| --- | --- |
| 새 탭 / 탭 닫기 | `⌘T` / `⌘W` |
| 다음 / 이전 탭 | `⌘⇧]` / `⌘⇧[` |
| 좌우 / 상하 분할 | `⌘D` / `⌘⇧D` |
| 인접 분할 창으로 이동 | `⌘⌥` + 방향키 |
| 분할 창 위치 교환 | `⌘⇧` + 방향키 |
| 화면 구성 1–7 적용 | `⌘⌃1` … `⌘⌃7` |
| 이전 출력에서 검색 | `⌘F` |
| 이전 / 다음 프롬프트 | `⌘↑` / `⌘↓` |
| 마지막 명령 출력 복사 | `⌘⇧C` |

단축키는 설정에서 변경할 수 있습니다. 변경한 경우 현재 메뉴와 **설정 → 키(Keys)**의 표시가 우선합니다.

## 첫 작업 공간 만들기

1. `⌘D`로 좌우 분할합니다.
2. 한쪽에서 `⌘⇧D`를 눌러 상하로 한 번 더 나눕니다.
3. `⌘⌥`와 방향키로 이동하고, `⌘⇧`와 방향키로 위치를 교환합니다.

분할 창은 트리 구조이므로 여러 단계로 나눌 수 있습니다. 매번 경계를 끌어 조절할 필요 없이 `⌘⌃1`로 **20 / 60 / 20 열 구성**을 적용할 수도 있습니다. [화면 구성 프리셋](/ko/preset-layouts)에서 일곱 가지 구성을 확인하세요.

## 출력을 문서처럼 탐색하기

OSC 133 프롬프트 표시를 제공하는 셸에서는 줄이 아니라 명령 단위로 이동할 수 있습니다. `⌘↑`·`⌘↓`로 프롬프트를 오가고 `⌘⇧C`로 마지막 출력을 복사하세요. `⌘F`는 이전 출력에서 검색합니다.

출력의 파일 경로를 `⌘`를 누른 채 클릭하면 파일을 엽니다. `file.swift:42`와 같은 줄 번호도 인식합니다. [셸 통합](/ko/shell-integration)에 지원 범위를 설명했습니다.

## 취향에 맞게 설정하기

폰트, 테마, 커서, 배경 투명도와 흐림, 합자, 애니메이션과 저장할 출력 줄 수를 [설정](/ko/settings)에서 조정하세요.
