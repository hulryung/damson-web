# Damson user manual

Damson is a macOS terminal with tabs, split panes and bundled tools for terminal control, coding-agent tasks and desktop interaction.

**Documentation baseline: v0.8.2, September 14, 2026.** Menu labels follow the app. Check [release notes](https://github.com/hulryung/damson/releases) for subsequent changes.

| Task | Tool | Availability |
| --- | --- | --- |
| Shell commands, tabs and splits | Damson.app | Included |
| Targeted pane input and output | damson-cli | Bundled CLI |
| Agent groups and dependent tasks | damson-crew | Bundled CLI |
| Preserve processes during supported restarts | damson-keeper | Managed internally |
| Inspect, capture and operate another macOS app | damson-computer | Included since v0.8.0 |

Start with installation and terminal settings for everyday use. Use agent groups for interactive work, or managed workflows to connect dependencies and verification.

<Callout type="info">
Typing “build a game” into a shell does not automatically decompose the project. A coding agent and the orchestration skill plan the work; damson-crew executes the plan. Tests and actual play checks establish whether the result works.
</Callout>
